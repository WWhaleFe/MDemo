# 차분 퍼즈에서 찾은 경계

첫 실패 묶음에서 같은 원인의 입력 두 개만 남겼다. `input`은 재현용 입력, `swift`와 `rust`는 수정 전 출력이다. 현재 Rust 출력은 Swift와 일치한다.

- `date-double-boundary`: 시드 20261126. 500개 중 날짜 차이 116개. 2001 기준 Double 손실로 `1999-12-31T23:59:59.001-03:30`은 `.000Z`, `1969-12-31T23:59:59.999Z`는 `.998Z`로 기록한다.
- `json-double-boundary`: 시드 20262126. 보드 파일 1개 차이. `9740568903986940`은 지수 형태, 정확히 `.25`인 `2152022966501068.25`는 최단 십진수 `.2`로 쓴다.

Swift 빌드 환경 오류의 묶음은 내용 차이가 아니므로 보관하지 않는다. 재현하려면 각 `input` 폴더를 두 CLI에 전달한다. 수정 후 경계는 Rust 단위 테스트로도 검사한다.
